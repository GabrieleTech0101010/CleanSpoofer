## 🚀 Overview



CleanSpoofer provides an optimized command-line interface (CLI) tailored for managing local application environments and routine cache hygiene. Featuring a stylized ASCII art startup sequence and an intuitive menu, it ensures smooth and fast execution with zero background bloat.

## ✨ Features

* **Custom CLI Interface:** Clean, stylized ASCII art banner with dynamic color-coded output.
* **CFX Routine Management:** Automated handling of local FiveM/CitizenFX maintenance workflows.
* **Lightweight & Fast:** Built natively using Windows batch scripting (`.bat`) with zero external software dependencies.
* **Open Source:** Fully transparent structure allowing developers to inspect, modify, and expand the utility.
